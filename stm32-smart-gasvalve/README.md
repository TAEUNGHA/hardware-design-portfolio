# STM32 기반 스마트 가스밸브 안전 시스템 (스마트콕)

다중 센서로 가스 누출·화재·과열·사용자 이탈을 실시간 판단해 **서보모터로 가스밸브를 자동 차단**하고
부저·LED로 경보하는 임베디드 안전 시스템입니다. (2026 임베디드 SW 경진대회 · 자유공모)

**MCU:** STM32F103RBT6 · STM32CubeIDE / HAL

## 시스템 구성
- **센서**
  - MQ-4 가스 센서 (ADC) — 누출 농도
  - MLX90614 적외선 온도 센서 — 표면·주변 온도
  - HC-SR04 초음파 — 사용자(사람) 근접·이탈 감지
  - 불꽃 센서 (아날로그) — 화재 감지
- **액추에이터/알림**: 서보모터(밸브 개폐), 부저, 3색 LED(R/Y/G)

## 안전 판단 로직
- **가스**: 절대 raw 임계 + 지속 확정(경고 2100 / 위험 2300, 연속 5틱≈2.5s), **조리 중 둔감화**(cook mode)로 오작동 억제
- **온도**: 표면 과열(260℃ soft) · 주변 과열(70℃ hard) · **빈냄비 의심**(온도 상승 기울기)
- **불꽃**: 부팅 기준선 대비 상대 강하량으로 판정(연속 6틱≈3s 지속 시 화재 확정)
- **사용자 이탈**: 초음파 근접(2틱 지속) + 타이머로 재실 여부 판단 → **무인 상태 자동 차단**
- **거리 임계 보정 모드(S_CALIB)**: 버튼으로 진입, 측정 평균+여유로 임계 자동 설정
- **타이머 계층**: 부팅 워밍업 / 문제 유예 / 기본 세션 / 절대 세션 상한(안전 다중화)

## 폴더 구조
- `test3/` — **STM32CubeIDE 프로젝트** (`test3.ioc` 열면 복원)
  - `Core/Src/main.c` — 센서 처리·상태 판단·서보 제어 등 핵심 로직 / `Core/Inc`, `Core/Startup`
  - 프로젝트 설정: `.project`, `.cproject`, `.mxproject`, `.ioc`, 링커 스크립트, `.settings/`
- `cad/frame.stl` — 하드웨어 프레임 3D 모델

> 빌드 시 재생성되는 `Debug/`(오브젝트·바이너리)와 `Drivers/`(HAL 라이브러리)는 제외했습니다.
> `test3.ioc`를 STM32CubeIDE(CubeMX)에서 열고 코드 생성을 실행하면 HAL Drivers가 복원됩니다.

**Tools:** STM32F103 · C · STM32CubeIDE / HAL · 다중 센서·서보 제어
